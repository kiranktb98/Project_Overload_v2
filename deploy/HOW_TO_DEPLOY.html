Project Overload v2

Self-hosted deployment guide — Docker Compose on a local server

What's in this package

  • docker-compose.yml Wires all 5 services together
  • Dockerfile.api API server + Chromium for PDF rendering
  • Dockerfile.web Web frontend server
  • Dockerfile.worker Background job worker
  • .dockerignore Prevents secrets/node_modules from entering the build
  • HOW_TO_DEPLOY.html This file
These files belong at the root of the Project Overload v2 repository. They do not run standalone — they need the full source code beside them.

Prerequisites

The server machine needs:

  • Docker Desktop (Mac/Windows) or Docker Engine + Docker Compose v2 (Linux) — docker compose version must work
  • Git — to clone the repository
  • ~4 GB free disk space — for images and Postgres data
  • An OpenRouter API key — required for LLM features

Step-by-step installation

1 Get the source code

git clone <repo-url> project-overload-v2
cd project-overload-v2

If you received a zip instead of a git URL, unzip it and cd into the folder.

2 Place the Docker files

Copy the files from this package into the repo root exactly as shown:

project-overload-v2/
├── docker-compose.yml        ← copy here
├── .dockerignore             ← copy here
└── apps/
    ├── api/
    │   └── Dockerfile        ← rename Dockerfile.api → Dockerfile, place here
    ├── web/
    │   └── Dockerfile        ← rename Dockerfile.web → Dockerfile, place here
    └── worker/
        └── Dockerfile        ← rename Dockerfile.worker → Dockerfile, place here
The three Dockerfiles must be renamed to exactly Dockerfile (no extension) and placed inside their respective app folders.

3 Create your .env file

cp .env.example .env

Then open .env in any text editor and fill in the required values:

VariableRequired?What to put
OPENROUTER_API_KEYrequiredYour OpenRouter API key — get one at openrouter.ai
APP_ENCRYPTION_KEYrequiredAny random 32-char string, e.g. run: openssl rand -hex 16
SESSION_SECRETrequiredAny random string, at least 32 characters
WEB_INTERNAL_API_KEYrequiredAny random string — used internally between web and api
DATABASE_URLauto-setDocker compose overrides this automatically — leave as-is
REDIS_URLauto-setDocker compose overrides this automatically — leave as-is
WEB_API_BASE_URLauto-setDocker compose overrides this automatically — leave as-is
Never commit your .env file to git. It is already in .gitignore.

4 Build the Docker images

This takes 3–10 minutes on first run (downloads Node, Chromium, installs dependencies):

docker compose build

5 Run the database migration one-time only

This creates all tables. Only needed once (or after schema changes):

docker compose run --rm api pnpm db:migrate

6 Start all services

docker compose up -d

Wait ~30 seconds for Postgres to initialize, then open:

http://localhost:3000
If you see the Project Overload UI, you're done.

Verify everything is running

docker compose ps

All five services should show running. If any show exited, check logs:

docker compose logs api
docker compose logs web
docker compose logs worker

Troubleshooting

API container exits immediately

Run docker compose logs api. Most likely cause: missing APP_ENCRYPTION_KEY or DATABASE_URL not reachable. Check your .env.

Port already in use

Something else is using port 3000 or 4000. Either stop that process or change the port mapping in docker-compose.yml (left side of the colon: "3001:3000").

PDF export not working

The API image installs Chromium automatically. If it fails, check docker compose logs api for Chrome not found. Set CHROME_PATH=/usr/bin/chromium in your .env.

LLM calls fail / no responses

Verify OPENROUTER_API_KEY is set correctly in .env and your OpenRouter account has credits.
