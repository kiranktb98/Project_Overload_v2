# Portfolio Signals

Reference repo reviewed: `https://github.com/KpG782/3D_Portfolio`

## What To Borrow

### 1. Clear atmospheric layering

The strongest part of the reference is not the 3D model. It is the page atmosphere:

- ambient radial gradients
- distinct surface layers
- bright accent highlights
- readable dark-mode contrast

This works well for analytics products because it adds depth without requiring new interaction models.

### 2. Better typography contrast

The reference uses a more polished sans voice and cleaner weight separation:

- strong headlines
- softer supporting copy
- restrained metadata

For product UI, this translates into:

- better page headers
- stronger card titles
- more legible empty states

### 3. Premium shell treatment

Useful shell patterns from the reference:

- sticky/floating top navigation feel
- darker base surfaces with brighter active states
- cards that feel elevated rather than flat
- controlled accent use instead of coloring everything

### 4. Motion with intent

The reference uses motion as reinforcement:

- hover lift
- active navigation emphasis
- reveal transitions

That is suitable for product UI if kept subtle.

## What Not To Borrow

- Do not copy the portfolio’s structure or section rhythm directly.
- Do not force 3D models into analytics workflows.
- Do not turn task-heavy pages into hero-driven landing pages.
- Do not add continuous background animation that competes with reading.

## Translation Pattern For Product UI

Use this mapping:

- portfolio hero atmosphere -> page lead / empty-state framing
- floating nav treatment -> stronger product shell
- glow cards -> premium metric or action cards
- reveal transitions -> subtle shell and panel entry

Avoid this mapping:

- portfolio storytelling sections -> product workflow fragmentation
- decorative 3D -> data/task distraction
