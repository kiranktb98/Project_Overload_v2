## Install On Another Codex Setup

Copy these folders into the other machine's Codex skills directory:

- `docs/codex-skills/analytics-ui-uplift`
- `docs/codex-skills/project-click-3d-ui`

Target location:

- Windows: `%USERPROFILE%\\.codex\\skills\\`
- macOS/Linux: `~/.codex/skills/`

After copying, the destination should look like:

- `%USERPROFILE%\\.codex\\skills\\analytics-ui-uplift\\SKILL.md`
- `%USERPROFILE%\\.codex\\skills\\project-click-3d-ui\\SKILL.md`

Then Codex can use:

- `analytics-ui-uplift`
- `project-click-3d-ui`

for marketing and UI work on the Claritect website.
