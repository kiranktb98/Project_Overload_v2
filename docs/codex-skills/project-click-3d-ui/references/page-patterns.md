# Page Patterns

## Features Page Pattern

Build the page as one scroll-led story:

1. Present one event as a premium 3D image cluster.
2. Turn the cluster into a cull interview moment.
3. Show frames separating into keep, shortlist, and pass states.
4. Promote one chosen frame into an edit stage with a before/after treatment.
5. End on a final polished image with a confident CTA.

## Signed-In Product Surfaces

- Keep the luxury brand language, but tighten utility and clarity.
- Use restrained 3D framing around the product shell rather than full cinematic takeover.
- Let motion support comprehension, not distract from work.

## Copy Rules

- Speak to photographers and studios as customers.
- Emphasize calm, polish, confidence, speed, and fewer handoffs.
- Never mention scaffolds, testing, internal routes, implementation details, or fake workflows.
