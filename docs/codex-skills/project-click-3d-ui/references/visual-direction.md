# Visual Direction

## Brand Feel

- Aim for luxury, editorial, cinematic, and composed.
- Use calm premium surfaces with bold motion rather than noisy interfaces.
- Let spacing, lighting, scale, and sequencing create the richness.

## Reference Translation

### Apple cue

- Use disciplined typography and clean hierarchy.
- Keep surfaces precise, bright, and premium.
- Let product-like objects sit in generous space.
- Make each section feel deliberate and uncluttered.

### MSI cue

- Use stronger perspective, darker contrast accents, and more dramatic reveals.
- Let hero objects feel staged and spotlighted.
- Introduce bolder transitions and a higher sense of power during scroll.

## Palette Approach

- Use warm ivory, pearl, champagne, graphite, and deep evergreen as the main family.
- Use mint and amber sparingly as luminous accents.
- Keep gradients soft and premium; avoid loud saturation.

## Typography

- Prefer expressive editorial pairing: refined display face plus clean body face.
- Keep headings large and tightly set.
- Use concise customer-facing lines with conviction.

## Surface Language

- Layer translucent glass, satin cards, soft shadows, thin strokes, and luminous edges.
- Use rounded forms intentionally, not everywhere.
- Make repeated pills within a section consistent in height and radius.
