Concurrency

Users never queue behind each other. Every request flows through independent, parallel paths.

Node.js API

Async, non-blocking I/O. A single process handles hundreds of concurrent in-flight requests without waiting.

LLM API (OpenRouter)

Stateless HTTP requests. Charge per token, not per connection. 10 simultaneous queries cost the same as 10 sequential ones.

PostgreSQL

Connection pooling via PgBouncer. Each user's SQL runs independently. Handles 50+ concurrent queries easily.

PDF rendering

Puppeteer is memory-heavy. At scale, move to a dedicated worker with BullMQ queue to avoid starving the API server.

Scaling rule

API slow?

Upgrade box to 32GB or add another instance.

DB slow?

Upgrade Postgres tier. Add read replica.

PDFs backing up?

Upgrade worker or add a second one.

Rate limited?

Request increase or switch to Anthropic direct.

Customer Acquisition

Finding customers

All channels excluding LinkedIn outreach. Prioritized by cost, speed, and expected ROI.

Tier 1 — Free, start immediately

Cold email (targeted, not spam)

  • Buy 500 CFO / Head of Analytics contacts (Apollo.io, $50/mo)
  • 3-email sequences via Instantly.ai ($30/mo)
  • Lead with: "How long does it take your team to answer a board question?"
  • Target: 2-3% reply rate = 10-15 conversations

Communities

  • Reddit: r/analytics, r/BusinessIntelligence, r/datascience
  • Slack: dbt, Locally Optimistic, Data Engineering, RevOps Co-op
  • Indie Hackers: build story, revenue milestones
  • Answer real questions. People check your profile.

Hacker News — Show HN

  • Title: "Show HN: Ask your database anything, get a consultant-grade report"
  • Post Tuesday/Wednesday, 8-9am ET
  • Engage with every comment
  • HN audience = technical founders who buy tools

Twitter / X — Build in public

  • Screenshots, architecture, customer wins
  • Engage data/analytics Twitter
  • Contrarian takes on analytics hiring
  • Consistent posting compounds

Tier 2 — Small spend ($500-1,500/mo), weeks 2-4

Google Ads (high-intent search)

  • Keywords: "automated business reporting", "AI data analyst", "alternative to hiring data analyst"
  • Budget: $500-1,000/month
  • Dedicated landing page with one CTA: book a pilot
  • Expected: $20-60/click, 5-10% conversion = $200-600/lead

Content / SEO

  • 5-10 articles targeting buyer keywords
  • "How to automate executive reporting"
  • "AI vs hiring a data analyst"
  • Host on blog.claritect.ai — compounds over time

YouTube demos

  • 3-5 minute screen recordings of real questions answered
  • Cross-post as Twitter threads with screenshots
  • A 3-min demo converts better than 10 pages of copy

Newsletter sponsorships

  • Data Science Roundup (~$200-500/issue)
  • Analytics Engineering Roundup
  • Lenny's Newsletter ($5K+, premium audience)
  • One good sponsorship = 20-50 qualified visits

Tier 3 — Bigger spend, month 2+

AppSumo / marketplaces

Lifetime deal at $79-149 to get first 50-100 users. Lose per user but gain: reviews, testimonials, social proof for full-price sales.

Partnerships

Partner with dbt consultancies, data agencies, fractional CFO firms. 20% revenue share. 10 partners x 1 client/month = 10 customers.

Live webinars

Monthly "Ask your data anything — live" event. Connect sample DB, take audience questions. Record and reuse as content.
